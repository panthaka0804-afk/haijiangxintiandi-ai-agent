# 大橘邻里 - 技术选型定版

> 定版日期：2026-08-03

## 前端

| 端 | 技术栈 | 原因 |
|---|---|---|
| 用户端 | uni-app (Vue 3) | 一套代码→微信小程序+H5+大屏WebView，三触点一份代码 |
| 管理后台 | Vue 3 + Element Plus | 纯PC浏览器，表格表单弹窗图表全现成 |

## 后端

| 层 | 技术 | 原因 |
|---|---|---|
| 框架 | FastAPI | 自动 `/docs` 文档页，协作不靠问 |
| ORM | SQLAlchemy | 换库改一行连接串 |
| 数据库 | SQLite → PostgreSQL | 试点期SQLite够用，多租户/并发/报表时迁移 |
| 大模型 | 独立 service 模块 | 换模型只改一个文件，方便单独测试 |

## 部署

| 组件 | 角色 |
|---|---|
| Caddy | 入口：自动HTTPS + 静态文件托管 + `/api/*` 反代uvicorn |
| uvicorn | 跑 FastAPI |
| 单机 | 全部，不需要容器编排 |

## 落地节奏

1. **不动** Flask + HTML 单体 → 撑完招商演示
2. **后端先行** 签约后 FastAPI 翻写（接口路径不变，老页面无缝继续用）
3. **再上前台** Vue 3 管理后台
4. **最后小程** 小程序立项时 uni-app 写用户端

每步结束时系统完整可演示。
