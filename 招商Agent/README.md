# 商业综合体招商落位AI Agent v1.0

## 怎么运行

双击或用命令行运行：
```
python agent.py
```

会弹出五个模块的菜单，输入数字选择功能。

或者直接运行测试看看所有功能：
```
python test.py
```

## 五个模块

| 编号 | 模块 | 功能 |
|------|------|------|
| 1 | 品牌智能匹配 | 输入面积/客群/品类/楼层 → 输出匹配品牌排行 |
| 2 | 落位方案生成 | 输入项目信息 → 输出各楼层业态和品牌建议 |
| 3 | 竞品排布分析 | 输入双方品牌列表 → 输出差距和建议 |
| 4 | 业态配比诊断 | 输入已有品牌 → 诊断业态是否健康 |
| 5 | 招商进度看板 | 输入签约数据 → 输出进度和预警 |

## 怎么加品牌数据

打开 `brands_data.py`，照着已有品牌的格式粘贴：

```python
{"name": "品牌名", "category": "品类", "subcategory": "子品类", 
 "price_range": "价格带", "area_need": "面积需求", 
 "target_crowd": "目标客群", "floors": "适配楼层", 
 "expansion": "扩张意愿", "avg_rent_bear": "租金承受",
 "competitors": ["竞品1", "竞品2"], 
 "complementary": ["互补品牌1"]},
```

## 怎么改规则

打开 `rules.py`，修改业态配比、楼层规则、竞合规则。
